StatLab Zim

An interactive statistics lab — from upload to insight.

Full app: CSV upload → quality check → descriptives → 6 charts → 5 tests → export

StatLab Zim is my attempt to make introductory statistics usable. No SPSS, no syntax — just a CSV. It handles messy real-world files: missing cells, duplicate rows, mixed types. You get a 13-metric numeric summary (mean, median, IQR, skew, kurtosis, CV), categorical frequency tables, 6 interactive Plotly charts (histogram, boxplot, bar, scatter, line for dates, heatmap), and 5 tests with plain-language decisions (Pearson, Spearman, linear regression with trendline, Welch t-test, chi-square).

Built solo in Python: pandas, SciPy, Plotly, Streamlit. 19 pytest tests, graceful empty-state handling, CSV/PNG exports via kaleido. The hardest part wasn’t the stats — it was the empty file with only a header edge case.
